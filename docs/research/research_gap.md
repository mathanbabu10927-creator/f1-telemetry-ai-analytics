# Research Gap — Living Document

This document must evolve as the literature and data investigation progresses.

For each candidate gap, record:

- Problem
- Existing approaches
- Available data
- Missing capability
- Proposed contribution
- Baseline methods
- Validation strategy
- Relevant papers
- Relevant prior art/patents
- Feasibility risks
- Evidence supporting the gap

Do not label a gap as novel until the evidence has been reviewed.
