# Project Scope

## In Scope

- Publicly accessible real-world F1/motorsport data
- Data provenance and licensing analysis
- Ingestion, validation, cleaning, and normalization
- Temporal/spatial alignment where supported
- Feature engineering
- Driver and lap/segment analysis
- Tyre and strategy analysis
- Vehicle/signal anomaly analysis where appropriate data exists
- Interactive visualization
- Reproducible experiments and evaluation

## Out of Scope

- Private or confidential team telemetry
- Claims about unavailable ECU/PU/sensor streams
- Redistribution of restricted datasets
- Treating simulator data as real measurements
- Novelty or patent claims without supporting evidence

## Data Classification

1. Public real-world measured/official
2. Publicly derived real-world
3. Simulator-generated
4. Model-derived/inferred
5. Private/confidential

Classes 1 and 2 are the primary focus.
