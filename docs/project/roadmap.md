# Project Roadmap

## Phase 1 — Data & Research Feasibility
- Identify candidate real-world data sources
- Verify 2026 coverage
- Record fields, resolution, format, licensing, and access
- Review existing research
- Identify candidate research gaps

## Phase 2 — Data Foundation
- Implement ingestion adapters
- Define canonical schemas
- Add validation and provenance
- Build preprocessing and alignment utilities

## Phase 3 — Analytical Modules
- Driver performance and delta
- Tyre degradation and strategy
- Vehicle/signal anomaly analysis
- Spatial track analytics

## Phase 4 — Evaluation
- Establish baselines
- Run controlled experiments
- Quantify errors and robustness
- Cross-session/circuit validation where possible

## Phase 5 — Integration
- Integrate analytical modules
- Build visualization/UI
- Document reproducible workflows

## Phase 6 — Research Output
- Finalize contribution
- Compare against existing work
- Document limitations
- Prepare paper/presentation/patent investigation if justified
